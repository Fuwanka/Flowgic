## Где смотреть

- `.local/document-eval-ru/public-cases-v1/review.html` — отобранные страницы с заметками;
- `.local/document-eval-ru/public-cases-v1/manifest.jsonl` — 37 полей на каждый случай,
  все пока `unreviewed`; есть связь с оригиналом PDF и исходным номером страницы;
- `.local/document-eval-ru/public-v2/review.html` — реестр всех попыток скачивания;
- `.local/document-eval-ru/public-v2/originals/` — неизменённые PDF;
- `.local/document-eval-ru/public-v2/text/` — вспомогательный текст, не эталон OCR.

Не смешивать этот корпус с прежним снимком FlowVision. Все публичные случаи имеют
split `public_development`, неизвестную экспозицию в предобучении и запрет автоматического
допуска в независимый holdout. Материалы одного пособия/источника сохраняют общую
группу: их нельзя разнести между обучением и проверкой как независимые источники.
Связанные компании/шаблоны из разных сайтов дополнительно требуют поиска дубликатов.

Публичный доступ не устанавливает права на обучение или перепубликацию. Сейчас
сохранены `rights_status=not_established`, `training_allowed=false`; сбор предназначен
для локального изучения и подготовки разметки, файлы не опубликованы.

## Существенные замечания после просмотра

- В пособии РосНОУ на стр. 61 условие задачи описывает стройсмеси, но встроенная
  форма содержит другой груз. Эти данные нельзя объединять в один эталон; используем
  содержимое формы, а текст условия оставляем контекстной ловушкой. Стр. 62 —
  продолжение формы. Стр. 64 — отдельный отрицательный пример путевого листа.
- Паспорт щебня содержит два блока на листе, значения плотности и показателей
  качества. Их нельзя принимать за массу рейса, даже если рядом есть слово «накладная».
- В бланке заявки напечатан год и проценты штрафа. Год не является полной датой
  документа, процент штрафа не является ставкой НДС.
- В розничных шаблонах УПД заполнены реквизиты покупателя, а товары отсутствуют;
  нули в формулах не доказывают поставку с нулевой стоимостью.
- Строительный пример ТОРГ-12 содержит товары и монтажные услуги, дробные количества,
  разные единицы и незаполненные цены. Массу нельзя получать из этих чисел произвольно.

Основной запрос на стройматериалы сохраняется: особенно не хватает реальных
заполненных ТН по песку/щебню/бетону, весовых талонов и представлений ЭТрН от операторов.
Найденное условие задачи про стройсмеси не засчитано как заполненная накладная на них.
Подборка даёт начальное разнообразие бланков, но не закрывает квоту 160 документов.

## Воспроизведение

```powershell
# Python с pypdf; pdftoppm должен быть в PATH. Новый каталог для каждого снимка.
python tools/document_eval/collect_public.py --output .local/document-eval-ru/public-next --render
python tools/document_eval/curate_public.py --source .local/document-eval-ru/public-next --output .local/document-eval-ru/public-cases-next
python tools/document_eval/verify.py .local/document-eval-ru/public-cases-next
```

Рендеры PNG нужны для проверки и подачи изображений модели. Исходные PDF не
пересохраняются. Библиотека pypdf извлекает текст только как вспомогательный слой.
Сетевые и TLS-ошибки регистрируются в результатах, а не заменяются пустыми документами.
